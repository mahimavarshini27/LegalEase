# ⚖️ LegalEase

## AI-Powered Legal Document Generator

LegalEase is an AI-powered web application that helps users generate customizable legal document drafts quickly and easily.

## 🚀 Features

- 🤖 AI-powered legal document generation
- 📋 Employment Contract generation
- 🏠 Lease Agreement generation
- 🔒 Non-Disclosure Agreement (NDA) generation
- ✏️ Edit and preview generated documents
- 📄 Download documents as DOCX
- 📕 Download documents as PDF
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- FastAPI
- Google Gemini AI
- python-docx
- FPDF
- Requests
- python-dotenv
